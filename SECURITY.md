# Security Policy

These packages run inside dApps next to a wallet, so we treat security reports for them with priority.

## Reporting a vulnerability

Please **do not** report vulnerabilities through public issues, discussions or pull requests. Email:

**security@qore.network**

Include, as far as you can: a description and the impact, steps to reproduce or a proof of concept, the affected package and version, and a suggested fix.

Qualifying reports are eligible for the QoreChain bug bounty; scope and rules are published at <https://www.qorechain.io/security>.

## What to expect

- We acknowledge your report and keep you informed while we investigate.
- We coordinate disclosure with you once a fix is released.

## Supported versions

The packages are pre-1.0. Security fixes go into the latest minor version of each package.

## Scope

Report issues in the QoreX wallet itself to the same address. Issues in RainbowKit, wagmi, cosmos-kit, Interchain Kit or Synpress should also be reported upstream.
